# UI design references

Six AI-generated design concepts for Day, together. The first five illustrate future route planning, locked stops, disruption repair, and before/after comparison. The sixth follows the user's preference for a spacious agent workspace that emphasizes communication through the orchestrator. These are visual references, not implemented screens.

1. Editorial Atlas — ivory, forest, terracotta; cartographic editorial workspace.
2. Night Operations — charcoal, lime; compact route mission control.
3. Japanese Journal — paper, vermilion, indigo; Tokyo travel journal.
4. Route Laboratory — white, cobalt; precise before/after planning interface.
5. Cinematic Travel — petrol teal, sand; photography balanced with itinerary tools.
6. Spacious Agent Workspace — offwhite and cobalt; four agent cards, directional messages, and one conversation inspector. Itinerary is in a separate tab. Recommended for the college multi-agent demonstration.

Generated with the built-in image-generation tool. Full prompts are saved in prompts.json. Reference images are visual directions, not implementation specifications or verified travel data.
