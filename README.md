# Multi-Agent Travel Day Planner

Created by **Shoodler**

A proof of concept that makes four AI agents' collaboration visible: a planner coordinates transport, dining, and activities specialists to produce a day itinerary.

The application lives in [`travel-planner/`](travel-planner/README.md). The original brief is preserved in [`architecture-plan.md`](architecture-plan.md) and [`implementation-instructions.md`](implementation-instructions.md).

See the application README for setup, architecture, limitations, and verification commands.
